# Свои IPv6-адреса и подсети, которые нужно завернуть в AntiZapret (формат: адрес/длина)
# Полные IPv6-списки сервисов лежат в download/*-ips6.txt (Cloudflare, DigitalOcean, Google, Hetzner, OVH, Roblox, Telegram, Fastly)
# и подключаются автоматически, как IPv4-файлы download/*-ips.txt. Здесь - только свои дополнительные адреса.
# Amazon и Akamai в IPv6 не включены намеренно: у них тысячи префиксов, список маршрутов клиента (AllowedIPs, push route-ipv6) стал бы слишком большим.
# Домены из include-hosts получают Fake-IPv6 (fd00:30::/64), записи в этом файле нужны только для адресов по IPv6-литералу или без DNS.
# Префиксы Meta (Instagram, Facebook, WhatsApp) намеренно не добавлены: Instagram/Meta всегда идут по IPv4 (пустой AAAA в kresd).
#
