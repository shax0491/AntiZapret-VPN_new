Для того чтобы подключение antizapret-\*.ovpn заработало как надо на роутерах Keenetic, надо в начало файла antizapret-\*.ovpn дописать:

```
pull-filter ignore block-outside-dns
route 1.1.1.1
route 8.8.8.8
```

В разделе 'Общие настройки системы' нажать 'Изменить набор компонентов', добавить: 'Клиент и сервер OpenVPN', 'Фильтрация контента и блокировка рекламы при помощи облачных сервисов' и 'Протокол IPv6'. Не удаляйте IPv6: он используется как резервный транспорт до VPS.

На WAN-подключении включите IPv6/DHCPv6 и делегирование префикса, если провайдер его выдаёт. Не назначайте провайдерские DNS для IPv6. В Mode A сервер подавляет AAAA для tunnel/non-RU доменов, а RU-домены получают настоящие A/AAAA и идут напрямую. В Mode B OpenVPN получает ULA и `route-ipv6 ::/0`, а сервер делает NAT66 на выбранный egress. При `ROUTE_ALL=y` не добавляйте собственный широкий IPv6-маршрут в обход правил AntiZapret/Mihomo.

Проверка после подключения: `curl -4 icanhazip.com`, `curl -6 icanhazip.com`, затем DNS A/AAAA для RU-домена и для tunnel-домена. В Mode A внешний IPv6 провайдера не должен использоваться для заблокированного ресурса; в Mode B внешний IPv6 должен принадлежать VPS/Proton/WARP.

В параметрах нового OpenVPN-подключения поставить галочку: 'Получать маршруты от удаленной стороны', содержимое отредактированного файла antizapret-\*.ovpn скопировать в поле 'Конфигурация OpenVPN'

В разделе 'Кабель Ethernet' (или например 'Модем 3G/4G', если подключение через модем) поставить галочки во всех опциях 'Игнорировать DNS...'

В разделе 'Интернет-фильтры', на вкладке 'Контентный фильтр' поставить 'Режим фильтрации: Выключен'

Перейти на вкладку 'Настройка DNS', если в списке есть DNS сервера удалить их, нажимая 'Добавить сервер' добавить IP-адреса: 1.1.1.1 и 8.8.8.8 на 'Любой интерфейс', кликнуть на значок карандаша где написано 'Системный' и убрать галочку 'Транзит запросов'

Вместо 1.1.1.1 и 8.8.8.8 могут быть любые IP-адреса доступных DNS серверов, но IP-адреса добавленные в файл antizapret-\*.ovpn и на вкладке 'Настройка DNS' должны быть одинаковые
В данный момент только провайдер АКАДО блокирует сторонние DNS сервера и вместо 1.1.1.1 и 8.8.8.8 нужно прописывать их DNS: https://www.akado.ru/sub/faq/tehnicheskie-voprosy
