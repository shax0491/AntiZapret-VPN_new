Для того чтобы подключение antizapret-\*.ovpn заработало как надо на некоторых роутерах TP-Link, надо в начало файла antizapret-\*.ovpn вставить:

```
route 0.0.0.0 128.0.0.0 net_gateway
route 128.0.0.0 128.0.0.0 net_gateway
route 10.29.0.0 255.255.0.0
route 172.29.0.0 255.255.0.0
```

Если не заработало то тогда вставить в начало все содержимое файла с сервера /root/antizapret/result/tp-link-openvpn-routes.txt

Отключите на роутере протокол IPv6

Не забудьте в настройках роутера, там же где настраивается подключение OpenVPN, выбрать устройства для которых будет использоваться это VPN-подключение
